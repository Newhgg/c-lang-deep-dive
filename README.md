> **免费开源版** — 3D 图谱 + 精讲 HTML 已开源。

## 📦 你拿到什么

```
c-lang-deep-dive/
├── c3d.html              # 3D 学习图谱（88KB，Three.js 单文件）

├── LICENSE.md

```

## 🚀 使用方式

### 第一步：先看图谱（10 分钟）

双击 `c3d.html` 打开 3D 学习图谱。
- 中心枢纽点按章节跳转
- 每个星球=一个知识点，点上去看"作用/格式/示例/易错点/随堂练习"
- 已掌握的知识点标记金星环
- 支持 53 题题库模式

### 第二步：读精讲（2 周）

双击 `c-deep-dive.html` 打开揉碎精讲。
- **10 章 52 知识点**，每点固定结构：
  - 一句话本质 → 原理拆解 → 内存与地址图 → 常见错例（带真实报错）→ 记忆口诀 → 4 选 1 随堂自测（即时判分+解析）
- ← / → 键盘翻页，hash 路由 `#30` 直达第 30 知识点
- 本地进度自动保存

## ✨ 独家深度（与免费网课的最大差异）

| 章节 | 独家内容 |
|---|---|
| 第1章 | 预编译链四步分工（预处理→编译→汇编→链接）+ 二进制视角 |
| 第2章 | 内存布局图（栈/堆/全局/代码段）+ 地址变化 |
| 第3章 | 运算符优先级内存视角 + 位运算实际用途 |
| 第5章 | 数组 vs 指针内存布局差异（真实内存图） |
| 第7章 | 指针深度（多级指针/函数指针/指针数组）+ 常见 segfault 排查 |
| 第8章 | 结构体内存对齐 + 结构体数组 vs 数组结构体 |
| 第10章 | 多文件项目工程视角（编译单元、头文件、链接） |

**核心差异**：免费课讲"怎么用"，这套讲"为什么"和"内存里长什么样"。
